# Hisaab - Intelligent Trading Journal

Hisaab is a powerful, next-generation Trading Journal designed to help traders track, analyze, and improve their trading performance. With intuitive dashboards and deep AI-driven insights, Hisaab acts as your personal trading assistant, giving you the edge you need in the markets.

## 🚀 Features

- **Trade journal**: log trades with entry/exit, stop, target, strategy, screenshots and psychology fields (confidence, emotion, mistakes).
- **AI Insights and Daily Planner**: generated by an LLM, then checked against your computed trade metrics by a deterministic guardrail before you see them.
- **Analytics**: dashboard, P&L calendar with weekly totals, R-multiples, strategy breakdowns and revenge-trade detection.
- **Trading tools**: position-size, risk:reward and compounding calculators.
- **CSV export** of all your trades.
- **Eve agent**: a quant research chat backed by a local Python engine.

P&L figures are gross: brokerage and statutory charges are not yet deducted.

## 🛠️ Technology Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS & Radix UI
- **Database, auth and storage**: Supabase (Postgres with RLS, Supabase Auth, a private Storage bucket for screenshots)
- **AI**: Groq via the Vercel AI SDK
- **Analytics**: Vercel Analytics

## 🔐 Environment

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase project |
| `BROKER_ENCRYPTION_KEY` | Secret used to encrypt broker tokens. To rotate, move the old value to `BROKER_ENCRYPTION_KEY_PREVIOUS`; tokens are re-encrypted on their next sync. |
| `GROQ_API_KEY` | AI Insights, Daily Planner and Eve |
| `HISAAB_DEMO_EMAIL`, `HISAAB_DEMO_PASSWORD` | Optional shared demo account, signed in server-side by the "Try demo" button |
| `QUANT_BRIDGE_URL`, `EVE_MODEL`, `GROQ_BASE_URL` | Optional Eve settings |

Run `supabase_schema.sql` against the project to create tables, RLS policies and the private `trades` storage bucket.

## ⚡ Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
